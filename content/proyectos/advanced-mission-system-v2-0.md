🆕 What's New in V2.0:
Completely redesigned user interface for a sleeker, more intuitive experience.
Automatic Admin Tag: The first player to join now automatically receives the Admin tag—no manual setup required!
Mission Improvements: Collection missions now remove mission items from inventory, preventing exploits between players.
Individual Language Selection: Players can now choose their preferred language from the interface, enabling multi-language support for each player.
Full Compatibility with other custom add-ons, including custom items, mobs, and blocks.




🌟 Core Features:
Customizable Missions: Tailor each mission with unique objectives and challenges that suit your playstyle.
Reward System: Get rewarded with exciting items or currency upon mission completion.
Progress Tracking: Keep track of your progress with ease, ensuring you're always on the path to success.
Completion Alerts: Receive notifications when you complete a mission, making every success feel even more rewarding.
Mission Variety: Four mission categories to keep the gameplay fresh and engaging.


How to Use:
Admin Setup: The first player automatically receives the "Admin" tag for full control.
Alternatively, add the tag manually using: /tag @s add Admin
Creating Missions: With Admin permissions, design missions in just a few steps.
Reward Setup: Create a scoreboard for rewards with the command: /scoreboard objectives add <scoreboard_name>
Or use the default scoreboard called money included in the add-on.
